# STM32F407 LCD 轮询与 DMA 真机对照

2026-11-17。使用同一块 STM32F407 板、同一份 RAM 测试程序和 ST7789，每隔 500 ms 交替发送相同的 240×320 RGB565 全屏纯色。SPI SCK 实测 10.500 MHz。

| 模式 | 完整帧 | 平均每帧耗时 | 平均每帧 CPU 活动时间 | 按 500 ms 周期折算 |
| --- | ---: | ---: | ---: | ---: |
| 轮询 | 20 | 117.0471 ms | 117.046862 ms | 23.4094% |
| DMA | 19 | 117.0536 ms | 0.039342 ms | 0.0079% |

在该固定负载下，DMA 将平均每帧刷屏 CPU 活动时间从 117.05 ms 降至 39.3 µs，降幅 99.97%。两种模式的刷屏耗时均约 117 ms。

PB0 标记刷新窗口。PB1 标记刷屏任务运行与 LCD DMA 完成中断，可能计入任务运行期间的少量系统中断。PE9 区分模式。标记波形以 4 MS/s 采样，SPI 时钟以 24 MS/s 采样，并按样本序号计算频率。折算占比只对应此全屏填充负载的刷屏 CPU 活动。

调试用采集未纳入统计。完成后通过 ST-Link 复位，读回 VTOR 为 0x08010000。
